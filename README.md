## <a name="english"></a> 🇬🇧 English

A basic, modular command-line calculator built in C. 
This is a personal mini-project developed alongside my **CS50** journey to practice functions, control structures, and modular programming.

### 🛠️ Features
* **Basic Operations:** Addition, Subtraction, Multiplication, and Division.
* **Modular Design:** Independent functions acting as building blocks for each mathematical operation.

### 🚀 How to Compile and Run
To compile and run the program in your terminal, use the following commands:
```bash
gcc calculator.c -o calculator
./calculator
```
